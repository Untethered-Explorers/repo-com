# Release Notes

This directory holds per-version release notes for `repo-com`.

**There are no tagged releases.** As of 2026-09-24 the project is at a
specification stage: `docs/PRD.md` and `docs/features/` define the canonical v1
plan, the agent team and project skills are generated, and **no source code,
binary, or release artifact exists**. The only release-note document is
therefore the draft [unreleased.md](unreleased.md).

When the first release is tagged:

1. Create `<version>.md` here using the release-notes template.
2. Move the `[Unreleased]` section of [CHANGELOG.md](../../CHANGELOG.md) under the
   new version and date.
3. Link the new notes from `README.md` and the changelog.
